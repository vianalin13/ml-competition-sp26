# CSI500 Stock Selection Competition — Reproducibility README

## Overview

This project builds a machine learning ensemble model for CSI500 stock selection.

The final submission combines multiple XGBoost variants and a Ridge regression model into a weighted ensemble designed to improve robustness across different market conditions.

The pipeline:
1. Downloads and updates CSI500 market data
2. Builds technical and cross-sectional features
3. Trains multiple predictive models
4. Combines model scores into a weighted ensemble
5. Constructs a long-only portfolio subject to competition constraints
6. Outputs a submission CSV for Gradescope

# Ensemble

The final portfolio is generated by combining standardized model scores.

Ensemble weights:

```python
ENSEMBLE_WEIGHTS = {
    "xgb_aggressive_top30": 0.25,
    "xgb_stable_top50": 0.20,
    "xgb_conservative_top75": 0.20,
    "ridge": 0.35,
}
```

Each model score is standardized:

```python
(score - mean) / std
```

before weighted aggregation.

Final portfolio size:

```python
top_k = 50
```

# Validation Methodology

Validation uses rolling time-series cross validation with embargo periods to avoid leakage.

Configuration:

```python
VAL_DAYS = 10
EMBARGO_DAYS = 5
N_SPLITS = 6
STEP_DAYS = 20
```

For each split:

1. Train on historical data only
2. Apply embargo gap
3. Predict on a single as-of date
4. Hold portfolio through evaluation window
5. Measure:

   * Rank IC
   * Portfolio return
   * Benchmark return
   * Excess return

The evaluation logic mirrors the score_submission.py

# Notes

* All models are trained from scratch.
* No pretrained models or embeddings are used.
* No future information is used during training.
* Time-series splits and embargo periods are used to reduce leakage risk.
* All portfolios satisfy competition constraints before submission.
* The submitted portfolios were generated using ensemble.py with the configurations documented above.
